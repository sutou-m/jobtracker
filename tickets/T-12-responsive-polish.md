# T-12: レスポンシブ対応・UI整備

## 前提チケット
T-05（一覧）、T-07（登録）、T-08（詳細・編集）、T-09（フィルタ）

## 概要
「外出先でスマホから案件を見つけてすぐ登録したい」という要件に対応するため、全画面のモバイル表示を整備する。また、ユーザビリティ上の細かい改善を加える。

## 実装内容

### 1. 一覧画面のレスポンシブ対応
- `FilterBar`: スマホではフィルタを折りたたみ（アコーディオンまたはフィルタアイコンで開閉）
- `JobCard`: スマホでもタイトル・バッジ・単価が読みやすいレイアウト
- 横スクロールが発生しないよう `overflow-x: hidden` を確認

### 2. 登録画面のレスポンシブ対応
- URLフィールドと「自動取得」ボタンがスマホで縦並びになるよう調整
- フォーム全体のパディング調整（スマホでは `px-4`、PC では `px-0`）

### 3. 詳細・編集画面のレスポンシブ対応
- 「更新する」「削除する」ボタンがスマホで横並びにならないよう縦積みに変更

### 4. ヘッダーのスマホ対応
- アプリ名と「+ 案件を登録」ボタンが小さい画面で重ならないよう調整

### 5. UIの細かい改善
- 案件カードにホバーエフェクト追加（`hover:shadow-md` または `hover:border-[#2563EB]`）
- フォームのラベルに必須マーク（*）追加（URL フィールド）
- 取得成功時のフィードバック（「タイトル・概要を取得しました」のトースト or メッセージ）
- ページタイトルを `<title>` で設定（Next.js の `metadata` API）

```tsx
// app/layout.tsx
export const metadata = {
  title: 'JobTracker',
  description: '案件進捗管理ツール',
}

// app/new/page.tsx
export const metadata = {
  title: '案件登録 | JobTracker',
}
```

### 6. ブレークポイント方針
- `sm:` (640px)以上をPC表示として扱う
- 基本はモバイルファーストで記述する

### 対象ファイル
- `app/globals.css`
- `app/layout.tsx`
- `components/Header.tsx`
- `components/FilterBar.tsx`
- `components/JobCard.tsx`
- `app/new/page.tsx`
- `app/jobs/[id]/JobEditForm.tsx`

## 注意事項
- Tailwind v4の `sm:` `md:` などのブレークポイントプレフィックスはそのまま使える
- ボタンの色変更は行わない（T-02で確定したHEXリテラルを維持する）
- スマホでの入力しやすさを優先するため、`<input type="url">` はスマホキーボードでURLモードになることを確認する
